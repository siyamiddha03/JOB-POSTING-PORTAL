# Hirely — Modern Job Posting Portal

A sleek, responsive, and interactive job posting and discovery web application built with HTML5, CSS3, and JavaScript.

## Features

- **Dynamic Job Listings**: Browse, filter, and search job openings by keyword, category, job type, and experience level.
- **Job Details & Application Flow**: View comprehensive job details and submit applications seamlessly.
- **Save Jobs**: Bookmark favorite positions for quick access later.
- **Post a Job**: Employer portal form to post new vacancies with custom tags, requirements, and salary ranges.
- **Modern UI/UX**: Clean dark/light-friendly design with smooth transitions, loading screen, and responsive layout for all devices.

## Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Custom modern styling with CSS variables and responsive design
- **JavaScript (ES6+)**: Interactive client-side state management and DOM manipulation

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/siyamiddha03/JOB-POSTING-PORTAL.git
   ```
2. Open `index.html` directly in any modern browser, or serve it using Live Server / any local static server.
